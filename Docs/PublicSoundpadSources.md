# Источники для публичного саундпада

Старый неподтверждённый мемный набор удалён. Для публичной Steam-версии
используется отдельная папка `Assets/PublicSoundboard` и только 21 проверенный
файл из её манифеста. Полная фиксация происхождения находится в
`Assets/PublicSoundboard/SOURCES.md`.

Настоящие фрагменты аниме, фильмов, сериалов, игр, телепередач и песен нельзя
считать свободными только из-за популярности мема. Для публичного набора лучше
подбирать оригинальные звуки с похожим настроением: драматический удар,
удивление, смех, фанфара, провал, победный джингл, мультяшный прыжок или короткая
авторская реплика.

## Лучший вариант для реплик

Для коротких смешных фраз на разных языках безопаснее записать собственный
мини-набор с добровольцами:

- 8–12 одинаковых игровых смыслов на каждом языке;
- письменное разрешение использовать, изменять и коммерчески распространять запись;
- оригинальный WAV, имя исполнителя, дата и текст разрешения в папке источника;
- обработанные игровые MP3/OGG уже производить из этого оригинала.

Примеры нейтральных смыслов: «Оце так хід!», «Не вірю!», «Мені пощастило»,
«Ще раз», «Добре зіграно», «Ой ні», «Це було близько», «Джокер!».

## Чек-лист конкретного файла

1. Открыть именно страницу файла, а не только главную страницу сайта.
2. Проверить автора, лицензию и разрешение коммерческого использования.
3. Убедиться, что запись не является вырезкой из фильма, игры, аниме или песни.
4. Скачать оригинал и сохранить URL, дату и копию лицензии.
5. При необходимости указать автора в `THIRD_PARTY_NOTICES.md`.
6. Добавить строку в `Docs/AssetRegistry.md`.
7. Только после этого добавить путь в публичный манифест.

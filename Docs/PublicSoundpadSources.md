# Джерела публічного саундпада

Старий набір мемних уривків видалено. Публічна Steam-версія використовує лише файли з `Assets/PublicSoundboard` та його маніфесту. Детальне походження зберігається в `Assets/PublicSoundboard/SOURCES.md`.

Уривки аніме, фільмів, серіалів, ігор, телепередач і пісень не стають вільними через популярність мема. Безпечна заміна — оригінальний звук із подібним настроєм: драматичний удар, подив, сміх, фанфара, провал, переможний джингл або коротка авторська репліка.

## Власні репліки

Найбезпечніший варіант — записати однаковий набір із 8–12 коротких ігрових реплік на кожній мові. Для кожного голосу слід зберегти оригінальний WAV, ім’я виконавця, дату й письмовий дозвіл на зміну та комерційне розповсюдження.

Приклади: «Оце так хід!», «Не вірю!», «Мені пощастило», «Ще раз», «Добре зіграно», «Ой ні», «Це було близько», «Джокер!».

## Перевірка нового файла

1. Відкрити сторінку конкретного файла або набору.
2. Зафіксувати автора, ліцензію та комерційний дозвіл.
3. Переконатися, що це не вирізка з захищеного твору.
4. Зберегти оригінал, URL, дату й копію ліцензії.
5. Додати потрібну атрибуцію до `THIRD_PARTY_NOTICES.md`.
6. Додати рядок до `Docs/AssetRegistry.md`.
7. Лише після цього додати шлях до публічного маніфесту.

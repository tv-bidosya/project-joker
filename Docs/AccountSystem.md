# Акаунти Project Joker

## Готовий перший етап

- Перший вихід у мережу без збереженого входу автоматично створює безплатний
  акаунт.
- Акаунт отримує постійний публічний ID формату `PJ-XXXXXXXXXXXXXXXX`.
- Кожний пристрій має власний випадковий 256-бітний токен.
- Профіль можна відновити на Android або ПК за Account ID і 128-бітним
  секретним кодом відновлення.
- Авторизований гравець може випустити новий код; попередній одразу стає
  недійсним.
- Ім'я та вбудований аватар зберігаються на сервері.
- Активне місце в незавершеній кімнаті прив'язане до Account ID, тому після
  відновлення на іншому пристрої можна повернутися за той самий стіл.

## Безпека

Токен пристрою та код відновлення не передаються мережею. Сервер надсилає
одноразовий випадковий challenge, а клієнт відповідає HMAC-SHA-256 доказом.
Challenge після однієї перевірки видаляється, тому перехоплену відповідь не
можна використати повторно.

У серверному JSON зберігаються лише SHA-256 verifier-и токенів і коду
відновлення. Файл записується через тимчасовий файл; попередня версія
залишається поруч із суфіксом `.bak`. На Oracle робочий шлях:
`/var/lib/project-joker-server/accounts.json`.

На клієнті зберігаються публічний Account ID і токен лише цього пристрою. Код
відновлення навмисно не записується в налаштування: після створення або заміни
його треба скопіювати й зберегти окремо.

## Що далі

1. Постійно зберігати незавершені й завершені матчі в серверній базі.
2. Нараховувати серверний XP рівно один раз за завершений матч.
3. Синхронізувати відкриту косметику та вибраний вигляд профілю.
4. Додати друзів, запити, блокування, скарги й сезонний рейтинг.
5. Додати необов'язкову прив'язку Google Play та Steam як додаткові способи
   входу, не змінюючи основний Account ID.

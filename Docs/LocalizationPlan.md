# План локализации

Godot позволяет переключать язык интерфейса во время работы через систему `TranslationServer`, поэтому отдельные сборки для каждого языка не нужны. Игрок выбирает язык в настройках, а выбор сохраняется между запусками.

## Первая публичная очередь

1. Українська — рекомендуемый язык по умолчанию для новой установки.
2. English.
3. Polski.
4. Беларуская.

Русский сейчас является исходным языком прототипа, потому что строки уже находятся в коде. Его присутствие в публичной версии остаётся отдельным решением автора и не входит автоматически в первый заявленный набор языков.

## Этапы внедрения

1. Собрать все пользовательские строки из сцен и GDScript, дать им стабильные ключи.
2. Подключить таблицы переводов и единый словарь названий мастей, режимов, действий Джокера и сетевых состояний.
3. Добавить выбор языка в настройки и компактный выбор при первом запуске.
4. Сохранять локаль в пользовательских настройках; при отсутствии выбора использовать украинский.
5. Проверить переносы, длинные имена, кнопки и панели на всех четырёх языках.
6. Отдельно перевести правила, обучение, сообщения ошибок, Steam-описание и список достижений.

## Текущий статус

- Подключён `TranslationServer` и общие CSV-таблицы для `uk`, `en`, `pl`, `be`,
  `kz` и временного исходного `ru`.
- На чистой установке до главного меню появляется выбор языка; рекомендуемым
  начальным вариантом является украинский.
- Старые установки без сохранённого поля локали продолжают использовать русский
  интерфейс прототипа, поэтому обновление не переключает язык неожиданно.
- Выбор языка доступен отдельным разделом настроек и сохраняется только на
  текущем устройстве.
- Переведены главное меню, создание локальной партии, основные разделы профиля
  и настроек, пауза, игровой стол, динамические фазы, панели игроков, козыри,
  история, чат, Джокер и основные состояния сетевого стола.
- Смена языка немедленно перестраивает уже открытый стол без перезапуска игры.
- Следующая редакторская проверка — вычитка длинных правил, редких сообщений
  ошибок и технических Steam-диагностик носителями каждого языка.

## Важные ограничения

- имя игрока, сообщения чата и названия личных аудиофайлов не переводятся;
- игровые события передаются по сети кодами и параметрами, а текст строится локально на языке каждого клиента;
- нельзя отправлять готовые русские фразы от хоста как часть игрового состояния — иначе игроки с разными языками увидят смешанный интерфейс;
- шрифт должен одновременно покрывать украинскую, белорусскую, польскую и английскую латиницу/кириллицу;
- перед релизом нужен ручной просмотр полного цикла на каждом языке, а не только машинная проверка наличия ключей.

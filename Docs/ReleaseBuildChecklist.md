# Чекліст релізної збірки

## Матеріали та ліцензії

- [ ] Усі файли експорту мають статус `готово` у [реєстрі матеріалів](AssetRegistry.md).
- [ ] `Assets/Soundboard` виключено з публічного PCK; використовується лише `Assets/PublicSoundboard`.
- [ ] У збірці немає тестових фотографій, особистої музики, старих мемних звуків і матеріалів із непідтвердженими правами.
- [ ] Поруч зі збіркою є `THIRD_PARTY_NOTICES.md` та потрібні тексти ліцензій.
- [ ] Перевірено іконку, шрифти, фони, аватари, карти, ефекти, Steam-шаблон і матеріали сторінки магазину.

## Мова й інтерфейс

- [ ] Нова установка запускається англійською.
- [ ] У публічному переліку Steam заявлено лише мови, реально доступні в грі.
- [ ] Українська, English, Polski та Қазақша пройшли ручний повний цикл у базовій збірці.
- [ ] Беларуская та російська не показуються без придбаного мовного пакета й не заявляються як базові мови.
- [ ] Єдиний пакет `Беларуская + Русский` відкриває обидві локалізації; цільова ціна для RUB-регіону встановлена на `322 ₽`.
- [ ] Відновлення покупки та перевірка права доступу працюють після перевстановлення й на новому пристрої.
- [ ] Меню розробника приховане.
- [ ] Назва, версія, видавець та іконка відповідають релізному пресету.

## Експорт Windows

1. Відкрити **Project → Export**.
2. Обрати актуальний пресет Windows/Steam.
3. Перевірити feature `public_release` і фільтри виключення.
4. Експортувати EXE та PCK до нової чистої папки.
5. Поточна інсталяція може вимагати **Export With Debug** через збій release-template `0xC0000094`; перед публікацією повторно перевірити новий шаблон.
6. Не розділяти EXE та PCK під час передавання друзям.

## Чиста перевірка

- [ ] Запустити збірку поза папкою проєкту на ПК без редактора Godot.
- [ ] Перевірити нову локальну гру, профіль, правила, налаштування та продовження збереження.
- [ ] Перевірити створення Steam-кімнати, запрошення, чотири живі акаунти та перепідключення.
- [ ] Пройти хоча б одну роздачу кожного спеціального типу.
- [ ] Перевірити створення `.pjreport` і відсутність особистих файлів у звіті.
- [ ] Звірити фактичний вміст PCK із реєстром матеріалів.

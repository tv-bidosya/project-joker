# Release-кандидат для Windows

Эта инструкция описывает полноценную Windows-сборку для тестеров или будущего релиза. Пока окончательные название и логотип не утверждены, допустимо собрать **release-кандидат** с рабочим названием `Project Joker`; для Steam-публикации перед выпуском нужно заменить их на финальные.

## Перед экспортом

- Заполнить строки для всех включаемых файлов в [`AssetRegistry.md`](AssetRegistry.md). Особенно проверить содержимое `Assets/Soundboard`: эти файлы попадают в `.pck` и распространяются вместе с игрой.
- Убедиться, что в игре нет личной музыки, фотографий, тестовых файлов и ассетов без подтверждённых прав.
- Личный плейлист игрока хранит только пути к файлам на его компьютере, не входит в `.pck` и при запуске не должен автоматически открывать внешний трек: новая сборка стартует с одной из трёх встроенных тем.
- Выбрать номер версии из четырёх частей для Windows, например `0.2.1.0`. Он должен совпадать с версией кандидата в описании сборки.
- Когда будут готовы, указать финальные название продукта, иконку `.ico`, описание и сведения о правообладателе в preset `Windows Release`.

## Экспорт в Godot

1. Открыть **Проект → Экспорт**.
2. Использовать единственный preset **Windows Desktop**. Для текущей установки Godot экспортировать с включённой галочкой **«Export With Debug»**.
3. Во время разработки в `Scripts/core/GameManager.gd` оставить `DEVELOPER_REPORT_TOOLS_ENABLED := true`. При запуске игры из редактора в меню будет внутренний раздел разработчика, через который можно открыть присланный `.pjreport`.
4. Экспортированная сборка автоматически скрывает внутренний раздел разработчика, даже если она собрана с **«Export With Debug»**. Менять переключатель перед отправкой игрокам больше не требуется; при необходимости его можно поставить в `false`, чтобы скрыть инструменты и в редакторе.
5. В папке игрока должны оказаться как минимум `ProjectJoker.exe` и `ProjectJoker.pck`. Их нужно передавать вместе, в одном архиве или папке.

Игрок всё ещё может использовать **Меню → Сообщить об ошибке** и прислать `.pjreport` разработчику. Чтобы посмотреть такой файл, разработчик оставляет переключатель в `true` и запускает игру из редактора.

### Отдельно: настоящий release-template

На текущей установке Godot 4.5 экспорт с выключенной **«Export With Debug»** аварийно завершает процесс Windows с кодом `0xC0000094` ещё до запуска игрового кода. Поэтому до обновления или переустановки export templates использовать его для друзей нельзя. Перед Steam-релизом обязательно вернуться к этому пункту: установить export templates точно той же версии, что редактор Godot, собрать чистый release без Debug и проверить его на отдельном компьютере.

## Проверка чистой сборки

- Распаковать архив в новую папку без файлов Godot.
- Запустить игру обычным двойным кликом по `.exe`.
- Проверить новую партию, сохранение/продолжение, звук, настройки, профиль, одну специальную раздачу и создание отчёта.
- Проверить на компьютере друга или в отдельной чистой учётной записи Windows.
- Сохранить архив, номер версии и короткий список изменений. Так легко вернуться к конкретной сборке, если тестер пришлёт отчёт.

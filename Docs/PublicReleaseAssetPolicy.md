# Політика матеріалів публічної збірки

## Єдиний публічний саундпад

- Steam-збірки використовують feature `public_release` і лише `Assets/PublicSoundboard/public_soundpad_manifest.gd`.
- Запуск із редактора без `public_release` може використовувати дзеркальний набір `Assets/Soundboard` для розробки.
- Публічний маніфест містить 21 перевірений файл: 19 звуків CC0 та дві оригінальні записи Project Joker.
- Експортний пресет обов’язково виключає всі аудіофайли `Assets/Soundboard`, інакше режим `all_resources` може покласти невикористані файли до PCK.

## Правило допуску

У публічну збірку потрапляє лише матеріал зі статусом `готово` у [реєстрі](AssetRegistry.md). Статуси `перевірити`, `лише закриті тести`, `замінити` та `виключити` забороняють публічний експорт.

Для CC BY, MIT, OFL та інших ліцензій із вимогою повідомлення повний текст і атрибуція постачаються разом із грою. Для CC0 також зберігається сторінка джерела як доказ походження.

## Перевірки перед релізом

- оригінальні аватари та іконка мають README з походженням і добре читаються у малих розмірах;
- пресет `Steam Friends Windows` містить `public_release`, виключає закритий саундпад і включає публічний;
- кожен активний AI-варіант Джокера внесено до реєстру окремо;
- перевірено фактичний PCK, шрифти, сторонні бібліотеки, Steam-шаблон і матеріали сторінки магазину;
- жоден файл не вважається дозволеним лише тому, що його можна безкоштовно завантажити з інтернету.

Project Joker Backup

Project Joker Backup is a private maintenance utility used by the owner of the Project Joker card game server and its associated Telegram bot.

What it does

The utility creates encrypted recovery archives of the game server, application configuration, and bot database. It uploads those archives to the owner's Google Drive account once per week.

Google Drive access

The utility requests the drive.file scope. It can access only files and folders that it creates itself and cannot inspect unrelated files already stored in the user's Drive.

Availability

This utility is not offered as a public service. It is operated solely by the owner for disaster recovery.

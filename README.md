# 🃏 Project Joker

Project Joker — современная реализация классического "Расписного покера" (Джокер, Одесский покер, Up & Down).

## Цель проекта

Создать лучшую цифровую версию игры с:

- Steam
- Онлайн мультиплеером
- ИИ-ботами
- Поддержкой разных правил
- Веб-версией

## Статус

🚧 В активной разработке

## Технологии

- Godot 4.5
- GDScript
- Git

# Project Joker

Цифровая версия авторских правил «Расписного покера» для четырёх игроков.

**Движок:** Godot Engine 4.5

## Правила

Каноничное описание правил находится в [Game Design Document](Docs/GameDesignDocument.md).
В нём зафиксированы порядок раздач, заказ взяток, правила хода, работа Джокера,
подсчёт очков и специальные режимы.

## Текущий статус

Готов прототип игровой модели:

- колода из 36 карт;
- Джокер — 7♣;
- перемешивание и взятие карт из колоды;
- заготовки типов раздач и козырей;
- консольная демонстрация работы колоды.

## Следующий этап

Реализовать локальную партию на четырёх игроков: руки игроков, раздачу,
заказ взяток, розыгрыш взяток и подсчёт результатов. После этого появятся
игровой интерфейс и сетевой режим.

# Публичный саундпад

Эта папка предназначена только для звуков, которые можно безопасно включать в
публичную коммерческую сборку Project Joker.

Для каждого добавленного файла обязательны:

- отдельная строка в `Docs/AssetRegistry.md`;
- автор и прямая ссылка на страницу конкретного файла или набора;
- лицензия, разрешающая коммерческое использование и распространение внутри игры;
- локальная копия текста лицензии, если она требует сохранения уведомления;
- запись в `public_soundpad_manifest.gd`.

Звуки из `Assets/Soundboard` являются набором для закрытых сборок друзьям. Они
не должны попадать в публичный экспорт и не могут автоматически переноситься
сюда только потому, что известны как мемы или свободно скачиваются из интернета.

# Публічний саундпад

Ця папка містить лише звуки, які дозволено включати до публічної комерційної збірки Project Joker.

Для кожного нового файла обов’язкові:

- окремий рядок у `Docs/AssetRegistry.md`;
- автор і пряме посилання на конкретний файл або набір;
- ліцензія, що дозволяє комерційне використання й поширення у грі;
- локальна копія тексту ліцензії, якщо вона вимагає збереження повідомлення;
- запис у `public_soundpad_manifest.gd`.

Набір містить 21 перевірений файл: 19 CC0-звуків OpenGameArt і дві оригінальні записи Project Joker. Авторів, посилання та умови наведено в `SOURCES.md`.

Публічний експорт повинен виключати `Assets/Soundboard`, щоб до PCK не потрапили дублікати або випадкові тестові записи.

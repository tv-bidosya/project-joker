# Fluent Emoji 3D subset

This directory contains the 30 three-dimensional PNG variants used by the
Project Joker social controls:

- reactions: twenty curated faces and gestures covering laughter, affection,
  approval, disagreement, surprise, sadness, anger, confusion and table banter;
- gifts: chocolate bar, hot beverage, beer mug, kiss mark, red heart, rose,
  shortcake, teddy bear, trophy and pile of poo.

Source: https://github.com/microsoft/fluentui-emoji

Copyright (c) Microsoft Corporation. The original repository and these selected

stored in `THIRD_PARTY_LICENSE.txt`.

The PNG files themselves are kept unchanged. Project Joker adds movement,
shadow and a shader-driven highlight at runtime in Godot.

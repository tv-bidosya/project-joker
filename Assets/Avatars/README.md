# Оригинальные аватары Project Joker

Четыре квадратных аватара созданы специально для Project Joker с помощью
OpenAI ImageGen 10 августа 2026 года и уменьшены до 512×512 PNG:

- `avatar_fox_v2.png` — хитрый Лис-картёжник;
- `avatar_clown.png` — добродушный карточный Клоун;
- `avatar_ace.png` — оригинальная аниме-вдохновлённая Чародейка;
- `avatar_mystery.png` — универсальная Тайна со знаком вопроса и картами.

Все персонажи требовались полностью оригинальными, без сходства с героями
фильмов, аниме, комиксов, игр, знаменитостями и реальными людьми. На картах нет
букв и знаков мастей. Использованы общие для игры глубокий изумрудный фон,
античное золото, бордовые и тёмные акценты. Пользователь может выбрать любой из
четырёх образов в профиле, а перед локальной партией — отдельно для каждого бота.

Сводные финальные промпты:

> Original square card-game avatar, polished semi-realistic 2.5D storybook
> portrait, centered close-up, strong silhouette at 90 px, deep emerald textured
> background and antique-gold rim light. Create respectively: a sly red fox card
> player; a friendly red-and-black card-table clown; an adult original
> anime-inspired card magician with midnight-blue hair; an ornate golden question
> mark among blank cards. No text, logos, watermarks, trademarks or resemblance
> to any existing character, franchise, celebrity or real person.

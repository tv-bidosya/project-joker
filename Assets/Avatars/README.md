# Аватары игроков

В этой папке лежат квадратные аватары, отображаемые рядом с игроками за столом.

Чтобы поставить свои изображения, замени один или несколько файлов, сохранив их имена:

- `avatar_fox.png` — Лис;
- `avatar_sun.png` — Солнце;
- `avatar_moon.png` — Луна;
- `avatar_spark.png` — Искра.

Лучше использовать квадратный PNG не меньше 256×256 пикселей. После замены Godot автоматически переимпортирует изображение; перезапусти запущенную партию, чтобы увидеть новый аватар.

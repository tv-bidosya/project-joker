# Оригінальні аватари Project Joker

Чотири квадратні аватари створено спеціально для Project Joker за допомогою OpenAI ImageGen 10 серпня 2026 року та зменшено до 512×512 PNG:

- `avatar_fox_v2.png` — хитрий Лис-картяр;
- `avatar_clown.png` — доброзичливий картковий Клоун;
- `avatar_ace.png` — оригінальна Чарівниця в аніме-стилі;
- `avatar_mystery.png` — універсальна Таємниця зі знаком питання й картами.

Персонажі створювалися повністю оригінальними, без схожості на героїв фільмів, аніме, коміксів, ігор, знаменитостей або реальних людей. На картах немає літер і знаків мастей. Використано спільні для гри глибокий смарагдовий фон, античне золото, бордові й темні акценти. Користувач може вибрати будь-який образ у профілі, а перед локальною партією — окремо для кожного бота.

Зведений фінальний промпт:

> Original square card-game avatar, polished semi-realistic 2.5D storybook
> portrait, centered close-up, strong silhouette at 90 px, deep emerald textured
> background and antique-gold rim light. Create respectively: a sly red fox card
> player; a friendly red-and-black card-table clown; an adult original
> anime-inspired card magician with midnight-blue hair; an ornate golden question
> mark among blank cards. No text, logos, watermarks, trademarks or resemblance
> to any existing character, franchise, celebrity or real person.

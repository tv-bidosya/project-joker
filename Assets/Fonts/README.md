# Project Joker fonts

The menu UI embeds three font families from the official [Google Fonts repository](https://github.com/google/fonts):

- `Forum-Regular.ttf` — atmospheric menu and page headings;
- `Vollkorn-Variable.ttf` — classic emerald-theme buttons and important controls;
- `Manrope-Variable.ttf` — body copy, technical descriptions, inputs, and Night City-theme controls.

Each family is distributed under the SIL Open Font License 1.1. The matching unmodified license text is stored beside the font as `Forum-OFL.txt`, `Vollkorn-OFL.txt`, and `Manrope-OFL.txt`. The files were downloaded from the `google/fonts` `main` branch on 2026-08-15 and are embedded without renaming or modifying the font binaries.

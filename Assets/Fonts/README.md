# Project Joker fonts

The menu UI uses Ukrainian-designed typefaces for its visible typography:

- `Arsenal-Bold.ttf` — headings; designed by Andrij Shevchenko and sourced from
  the official [Google Fonts repository](https://github.com/google/fonts);
- `FixelDisplay-SemiBold.ttf` — buttons and important controls;
- `FixelText-Medium.ttf` — body copy, technical descriptions, and inputs. Fixel
  is published by Ukrainian company MacPaw in its official
  [public repository](https://github.com/MacPaw/Fixel);
- `Vollkorn-Variable.ttf` — fallback for Kazakh Cyrillic and rare glyphs only,
  sourced from Google Fonts.

All families are distributed under the SIL Open Font License 1.1. The matching
unmodified license texts are stored beside the fonts as `Arsenal-OFL.txt`,
`Fixel-OFL.txt`, and `Vollkorn-OFL.txt`.

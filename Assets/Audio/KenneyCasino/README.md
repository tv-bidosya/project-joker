# Kenney Casino Audio

Selected sound effects from **Casino Audio 1.1** by Kenney Vleugels
(Kenney.nl).

- Source: https://kenney.nl/assets/casino-audio
- Download mirror used for the original archive:
  https://lpc.opengameart.org/content/54-casino-sound-effects-cards-dice-chips
- License: Creative Commons Zero 1.0 Universal (CC0)
- License text: `LICENSE.txt`
- Attribution is not required; the source is recorded here for provenance.

Project Joker uses the selected files as follows:

- `card-shuffle.ogg` — start/deal of a round;
- `card-place-*.ogg` — a card placed on the table;
- `card-shove-*.ogg` — collection of a completed trick;
- `chip-lay-*.ogg` — the local player's turn begins;
- `chips-collide-*.ogg` — recurring 10-second turn reminder.

The OGG files are kept unchanged from the downloaded pack.

# Project Joker UI artwork

`menu_card_salon_night_v2.png` and `menu_card_salon_day_v3.png` are original AI-assisted background artworks generated for Project Joker on 2026-08-14 with OpenAI's built-in image generation tool.

The night production prompt requested a wide dark-fantasy European card salon with a moonlit window, candlelit desk, emerald velvet and antique brass, a restrained original joker ornament, and a dark uncluttered centre for responsive Godot UI. A later precise edit replaced malformed lower-left cards with one consistent physical stack whose top card uses the original Project Joker card illustration from `Assets/Cards/VectorClassic/project_joker_crisp.png` as reference.

The day variant was derived from the corrected night composition by changing only time and lighting: clear late-morning sunlight outside the window, natural indirect light in the room, and every candle and lantern extinguished. A final precise edit added thin blue-gray smoke wisps above the recently extinguished candle wicks on the right without changing the menu-safe centre or the rest of the composition. All prompts explicitly excluded logos, text, interface elements, watermarks, people and recognizable copyrighted characters.

The menu controls, typography, panels and interaction states are rendered separately by Godot and are not baked into the image.

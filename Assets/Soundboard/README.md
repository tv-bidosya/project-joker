# Встроенный саундпад Project Joker

Эта папка содержит проверенный набор для локальных и закрытых сборок друзьям.
Во время партии игроки не загружают свои файлы: набор формирует разработчик
проекта. Текущий состав: 19 CC0-звуков OpenGameArt и две оригинальные записи
Project Joker.

Публичная Steam-сборка использует отдельные проверенные копии из папки
`Assets/PublicSoundboard`. Аудиофайлы отсюда исключаются из публичного PCK,
чтобы новые тестовые записи не могли попасть в релиз автоматически.
Подробности: `Docs/PublicReleaseAssetPolicy.md`.

## Как добавить звук

1. Положи файл в эту папку или в папку нужного языка, например `ua/applause.ogg`, `pl/beer.wav` или `en/hello.mp3`.
2. Перезапусти проект в Godot: саундпад автоматически подхватит все подходящие файлы и покажет их по имени в списке.
3. Экспортируй новую Windows-сборку, чтобы этот набор появился у друзей.

## Категории языков

Саундпад сначала показывает язык, затем — только звуки из соответствующей папки. Папки появляются в игре, только если внутри есть хотя бы один подходящий звук.

```text
Assets/Soundboard/
├── ua/       — Українська
├── pl/       — Polski
├── ru/       — Русский
├── en/       — English
├── kz/       — Қазақша
├── by/       — Беларуская
└── other/    — другие языки и общие категории
```

Файлы прямо в `Assets/Soundboard` остаются в категории «Общее». Можно создать и другую папку первого уровня: игра выведет её имя отдельной категорией. Более глубокие вложенные папки не сканируются.

## Ограничения

- Поддерживаются **OGG Vorbis**, **WAV** и **MP3**. Для сборки лучше всего использовать WAV или MP3. Файлы **Ogg Opus** Godot не импортирует — их нужно предварительно преобразовать в WAV, MP3 или OGG Vorbis.
- Один файл — не больше **2 МБ** и не длиннее **25 секунд**. Более крупные или длинные файлы игра пропускает.
- Оптимально: короткий, отчётливый звук длительностью до 25 секунд; 44,1 или 48 кГц.
- В панели отображается до 20 символов названия файла, полное название доступно во всплывающей подсказке.
- Громкость саундпада использует текущую настройку «Громкость эффектов».
- На одного игрока: **3 запуска**, затем отдельная **перезарядка 2 минуты**. Реакции, стикеры и саундпад считают свои лимиты независимо.

Добавляй только свои звуки, материалы с подходящей лицензией или звуки, на которые у проекта есть права.

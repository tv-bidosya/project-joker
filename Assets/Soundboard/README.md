# Вбудований саундпад Project Joker

Папка містить перевірений набір для локальної розробки й закритих тестів: 19 CC0-звуків OpenGameArt і дві оригінальні записи Project Joker. Набір формує розробник; гравці не додають файли під час партії.

Публічна Steam-збірка використовує окремі копії з `Assets/PublicSoundboard`. Цю папку виключено з публічного PCK, щоб тестові записи не потрапили до релізу випадково. Докладніше: `Docs/PublicReleaseAssetPolicy.md`.

## Як додати звук

1. Додайте файл сюди або до мовної папки, наприклад `ua/applause.ogg`, `pl/beer.wav` чи `en/hello.mp3`.
2. Перезапустіть проєкт у Godot: саундпад автоматично знайде підтримувані файли.
3. Експортуйте нову Windows-збірку, щоб набір з’явився у тестерів.

## Мовні категорії

```text
Assets/Soundboard/
├── ua/       — Українська
├── pl/       — Polski
├── en/       — English
├── kz/       — Қазақша
├── by/       — Беларуская
├── ru/       — внутрішня локалізація, не для базового публічного експорту
└── other/    — інші мови й загальні категорії
```

Файли в корені лишаються в категорії «Загальне». Дозволено створити іншу папку першого рівня; глибші вкладення не скануються.

## Обмеження

- Підтримуються OGG Vorbis, WAV і MP3. Ogg Opus потрібно перетворити.
- Не більше 2 МБ і 25 секунд на файл.
- Рекомендовано 44,1 або 48 кГц та короткий виразний звук.
- У панелі видно до 20 символів назви; повна назва є в підказці.
- Гучність використовує налаштування звукових ефектів.
- Один гравець має три запуски, потім окреме перезаряджання 2 хвилини.

Додавайте лише власні звуки або матеріали з підтвердженою придатною ліцензією.

# Вбудовані стікери Project Joker

Ця папка містить авторські стікери, що входять до збірки. Під час партії гравці не завантажують сюди зображення: файли додає розробник, після чого вони стають доступними всім у наступній версії.

## Як додати стікер

1. Підготуйте зображення з виразним силуетом. Найкраще підходить квадратний PNG або WebP із прозорим фоном, рекомендовано 256×256 px. JPG підтримується без прозорості.
2. Додайте файл до цієї папки, наприклад `beer.png`, `kiss.webp` або `heart.png`.
3. Перезапустіть проєкт у Godot, щоб рушій імпортував файл. Гра автоматично додає PNG, WebP та JPG/JPEG до списку стікерів.
4. Експортуйте нову Windows-збірку й передайте її тестерам.

Використовуйте лише власні зображення, матеріали з відповідною ліцензією або файли, на які проєкт має права.

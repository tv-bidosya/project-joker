# Встроенные стикеры Project Joker

Это папка для авторских стикеров, которые входят в сборку игры. Игроки не загружают сюда изображения во время партии: все файлы добавляет разработчик проекта, а затем они становятся доступны всем в следующей сборке.

## Как добавить стикер

1. Подготовь изображение с понятным силуэтом. Лучше всего подойдёт квадратный PNG или WebP с прозрачным фоном; рекомендуемый размер — 256×256 пикселей. JPG тоже поддерживается, но у него не будет прозрачности.
2. Помести файл в эту папку. Например: `beer.png`, `kiss.webp` или `heart.png`.
3. Перезапусти проект в Godot, чтобы движок импортировал новый файл. Игра автоматически добавит все PNG, WebP и JPG/JPEG из этой папки в выбор стикеров.
4. Экспортируй новую Windows-сборку и передай её друзьям: только так новый стикер появится у них.

Используй только свои изображения, изображения с подходящей лицензией или материалы, на которые у проекта есть права.

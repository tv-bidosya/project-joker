# Playing Cards (Vector & PNG)

Source: https://opengameart.org/content/playing-cards-vector-png

- Author: Byron Knoll
- Submitted to OpenGameArt by: Curt
- License shown on the source page: CC0
- Format used by Project Joker: high-resolution PNG exported from the vector originals

This project includes the 36 card faces needed for its 6-to-Ace deck and the red Joker. The full-art `2` variants are used for Jack, Queen, and King; the simpler `2` variant is used for the Ace of Spades. The PNG exports are used because Godot's SVG importer does not render the source deck's text layers, which removes card ranks. The shared Project Joker card back comes from the separate Jumbo Index CC0 set.

# Jumbo Index Playing Cards

Карты для Project Joker: классическая вертикальная колода с крупными индексами
(`Vertical2` из исходного архива).

- Источник: https://opengameart.org/content/jumbo-index-playing-cards
- Автор на OpenGameArt: saul
- Лицензия: CC0
- В проекте используются только карты рангов 6–туз, красный Джокер и синяя рубашка.

CC0 разрешает коммерческое использование, распространение и изменение без обязательной атрибуции.
Ссылку и сведения о лицензии всё равно сохраняем в реестре ассетов для будущей Steam-проверки.

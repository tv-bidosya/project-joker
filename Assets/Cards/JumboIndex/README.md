# Jumbo Index Playing Cards

Класична вертикальна колода з великими індексами (`Vertical2` з початкового архіву).

- Джерело: https://opengameart.org/content/jumbo-index-playing-cards
- Автор на OpenGameArt: saul
- Ліцензія: CC0
- У проєкті використовуються ранги від шістки до туза, червоний Джокер і синя сорочка.

CC0 дозволяє комерційне використання, поширення та зміну без обов’язкової атрибуції. Посилання й дані про ліцензію все одно зберігаються в реєстрі матеріалів для майбутньої Steam-перевірки.
